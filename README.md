# Simple Interest Calculator

A simple script to calculate simple interest based on principal amount, rate of interest, and time period in years.

## Formula
$$\text{Simple Interest} = \frac{\text{Principal} \times \text{Rate} \times \text{Time}}{100}$$

## Input Parameters:
- **p / Principal**: Initial amount of money
- **r / Rate**: Annual rate of interest (%)
- **t / Time**: Time period in years

## Output:
- Simple Interest amount
